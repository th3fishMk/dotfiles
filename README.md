# Dotfiles

Please keep in mind, this scrips are mostly mean to work in a fedora linux distribution, although some of them may run in other oss, fedora is the main target.

Long life to fedora.

Just run this command

```bash
git clone https://github.com/th3fishMk/dotfiles.git ~/.dotfiles && bash ~/.dotfiles/startup.sh
```

To make any new scripts executable, run:

```bash
chmod +x <filename>
```
