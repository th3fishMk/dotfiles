# Dotfiles

Just run this command

```bash
git clone https://codeberg.org/th3fishMk/dotfiles.git ~/.dotfiles && bash ~/.dotfiles/startup.sh
```

To make any new scripts executable, run:

```bash
chmod +x <filename>
```
